# J3: разделение вклада P/I токового регулятора, 2026-11-18

Продолжение [первой записи](g474-foc-j3-live-20261118.md). Оператор разрешил продолжение; подтверждённая механическая поддержка J3 сохранялась. Испытывалась только J3/node103, без позиционных проходов и без изменения наблюдателя, LPF, ADC/PWM/CAN timing или EEPROM. После каждого диагностического варианта исходное приложение возвращалось по CAN; после последнего восстановления J3 arm1 удерживает текущую позу, fault_act0, CAN tx/rx/bus-error counters0.

- **Ki0 не убрал колебания.** В Id и Vd сохраняется выраженный пик≈1250Гц.
- **Kp0.5/Ki0 подавил выраженный пик1250Гц до фонового уровня в данном окне.** Остаточный Id близок к VOLTAGE0. Это сильнее простого уменьшения колебаний за счёт отключения интегратора.

- Параметры проверены по самим записям: least-squares `Vd_pi_raw = Kp*id_error + Ki*id_integral_as` даёт соответственно (2,600), (2,≈0), (0.5,≈0), а после первого возврата снова (2,600). Согласованность формулы проверяет реально исполняемые коэффициенты, не устойчивость системы.

Максимум ISR body в measurement-окнах≤54.175мкс приT62.5мкс, зарегистрированных late/pending/NDTR-change/ADC OVR/DMA TE нет. В control-окнах нет насыщения. Признак NDTR-change не гарантирует полную целостность скана. Диагностические hooks увеличивают время исполнения; длительность цикла и preload не менялись.

## Фазовая картина

На1250Гц:

- LPF alpha0.0925 при16кГц: расчёт−64.98°, по обратному восстановлению raw из filtered в control-окне≈−64.73°.
- Дискретный PI `C(z)=2 + 600*T/(1-z⁻¹)`: фаза−2.12°, модуль≈2.020В/А. При Ki0 модуль2В/А: изменение всего≈1% на этой частоте.
- Записанный Vd относительно filtered Id≈+177.85°, что согласуется с отрицательной обратной связью и указанным PI.
- Raw Id относительно staged Vd≈−113.12°. Вместе с LPF/PI фазовая картина совместима с колебанием замкнутого контура.

Последнее отношение **не является независимой идентификацией мотора**: спонтанные колебания в обратной связи связывают I/V через сам контроллер. По нему нельзя достоверно вычислить R/L, фазовый запас или объявить единственную аппаратную задержку. В стабильном малошумном варианте выбор максимального FFT-бина вообще не доказывает существование собственной частоты; результаты `p05-phase.json` следует читать с этим ограничением.

## Что установлено и что остаётся

Токовый интегратор не является необходимым условием выявленного колебания. Шум энкодера похож при всех вариантах, тогда как изменение только токового Kp при Ki0 существенно меняет результат. Поэтому чисто энкодерное объяснение стало менее убедительным; наблюдатель сейчас менять оснований нет.

Локализовано взаимодействие усиления токовой обратной связи с реальным объектом и измерительным трактом. Пока не разделены вклад низкоиндуктивного мотора/R-L, фильтра/цифровой задержки и зависимых от PWM помех измерения. Уменьшение P может подавлять последствия нескольких таких причин; это не доказательство конкретного дефекта кода. Аналоговый ток независимо не измерялся, алиасинг выше8кГц остаётся возможным.

Kp0.5/Ki0 **не принят постоянной настройкой**: не проверены ненулевые токи, реверс, скорость, удержание под нагрузкой и другие J1–J4. Следующий обоснованный этап — оценить R/L и допустимую полосу токового контура, затем проверить выбранный PI ограниченными заданиями Iq. Позиционный Kp увеличивать и encoder gains менять по этим данным не нужно.
