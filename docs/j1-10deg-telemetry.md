# J1: +10° через trajectory controller, 2026-11-12

По явному запросу пользователя выполнен один поворот J1 +10° от измеренного начального положения. Ручной отмены не было. Профиль длительностью6с — quintic, предел задания скорости 0.055261рад/с. Остальные оси сохраняли прежние command references; коэффициенты не менялись. MoveIt в этом тесте не участвовал: цель передана напрямую через FollowJointTrajectory, чтобы отдельно проверить цепочку controller manager→hardware→привод.

Контроллер завершил цель успешно: status4, error_code0. Фактически пройдено 9.88756°, конечная ошибка 0.11244°. Максимальная ошибка слежения 0.81386°. Снято 1033 ROS-отсчётов; медианный шаг 0.01000011с, максимальный 0.01058125с.

ROS reference монотонный, максимальное приращение 0.032533° за отсчёт. Разрывов/перезапусков ROS-профиля на записи нет. Измеренное положение при этом колеблется вокруг reference: размах ошибки на участке1.7–5с 1.3016°, оценочная частота 3.704Гц. Сообщаемая приводом скорость на движении: -0.3288…0.3938рад/с, при максимальном ROS reference 0.0553рад/с. Оценка скорости содержит шум observer; в выводах следует учитывать также непосредственно измеренное положение.

Это исключает рывки генератора ROS на данном конкретном профиле, но не локализует источник колебаний между CAN-входом, внутренней целью прошивки, регулятором и механикой. J1 ещё использует прежнюю прошивку G474; правка потокового захвата применена пока только на J5.

Ограничение записи: отдельный CAN-рекордер завершился примерно за7.5с до отправки цели. Поэтому CAN-токи и внутренняя firmware-цель не записаны на движении; выдавать эту запись за полную синхронную трассу нельзя. Движение автоматически не повторялось.

Артефакты: `build/j1-10deg-test/goal.json`, `result.json`, `ros-state.jsonl`, `summary.json`, `telemetry.png`. Начальная позиция J1 -0.135371089рад, конечная цель 0.039161836рад. После теста привод оставлен на конечной цели; обратного движения не задавалось.
