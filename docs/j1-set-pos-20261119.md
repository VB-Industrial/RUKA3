# J1: отдельные проверки set_pos, 2026-11-19

Оператор разрешил работу после завершения параллельных проверок. ROS-контроллеры отсутствовали. Испытывался только node101; остальные приводы, EEPROM, прошивка и ROS-конфигурация не изменялись. Использован обычный CAN Register Access `set_pos` с относительными проходами по 10°; коэффициенты менялись только в RAM.

Исходно: arm1, Kp30, Kd0, Ki1, i_limit1 А, fault0. i_limit ограничивает интегральную добавку, а не полный ток FOC; фактический предел тока в диагностике 10 А. Заданный профиль по текущему коду: vmax0.5 рад/с, amax1 рад/с², 100 Гц; для 10° профиль треугольный, около0.84 с. Это не проверка медленной постоянной скорости уровня MoveIt.

| Проход | Kp/Kd/Ki | Направление | max ошибка профиля | Перелёт после профиля | Размах положения за последние2с | max Iq target |
|---|---|---|---:|---:|---:|---:|
| baseline |30/0/1|+10°|1.167°|0.393°|0.088°|0.880 А|
| kd1 |30/1/1|−10°|1.202°|0.263°|0.044°|0.742 А|
| kd3 |30/3/1|+10°|1.450°|0.767°|1.714°|2.995 А|

Во всех трёх записях feedback fault=false. Внутренний профиль плавный; baseline содержит колебания скорости, измеренный Iq в доступных снимках следует заданию. Проба Kd3 ухудшила удержание и RMS ошибки измеренного Iq относительно target (0.584 А против0.045 А baseline). Сравнение baseline/kd1 имеет разные направления, поэтому уменьшение колебаний нельзя полностью приписать D без повторов одинаковых проходов. Kd1 пока только кандидат, настройка не завершена.

После обнаружения ухудшения предпринята попытка вернуть Kd1 и провести обратный проход. **SSH до выполнения команды перестал быть доступен: No route to host / timeout.** Файл kd1_repeat.jsonl пуст, этот проход не выполнялся. Последнее подтверждённое значение Kd=3; откат пока не подтверждён. Оператор уведомлён о необходимости поддержать руку при колебаниях и проверить питание/сеть Pi. Подготовлен отдельный rollback_kd.py: меняет только Kd на1, не задаёт новую позицию. До восстановления связи новых движений не выполнять.

Артефакты: `build/set-pos-j1-20261119/`: preflight.jsonl, baseline.jsonl, kd1.jsonl, kd3.jsonl, summary.json, comparison.png, trial.py, analyze.py, rollback_kd.py. Повторный анализ: `python3 build/set-pos-j1-20261119/analyze.py baseline kd1 kd3`.
