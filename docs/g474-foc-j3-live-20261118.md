# J3: первая высокочастотная запись FOC, 2026-11-18

Оператор подтвердил механическую поддержку J3 для потери удержания при обновлении. J3/node103 обновлена по CAN диагностическим приложением, bootloader и EEPROM не переписывались. SHA256 приложения: `5a37485b51950517921248d5946a96227e857c5724d2a2d77fcdf7a3feff3888`.

Артефакты: `build/foc-audit/j3-live-20261118/`. До обновления снята отдельная низкочастотная запись `before-flash.jsonl`; она не склеивается с новой записью. После старта приложение было разоружено. Все сравнения ниже сняты **после** обновления, около одного положения ротора raw≈1016 и электрического угла≈1.51рад. Старую позиционную цель после перезапуска не восстанавливали.

## Условия

256 последовательных периодов ×62.5мкс, по16мс на профиль; три профиля сняты последовательно, не одновременно. PI тока Kp2/Ki600 и LPFalpha0.0925 остались исходными. Позиционные gains вручную не подбирались: перезапуск возвращает штатные defaults, arm захватывает текущую позу. Поэтому runtime Kp10 до перезапуска не считается сохранённым. Ki верхнего уровня до теста=0, load addition отсутствует.

1. `off-*`: каскад логически выключен.
2. `on-*`: удержание захваченной текущей позы; Iq target практически0, в control-окне от−0.00119 до+0.00152А.
3. `zero-voltage-*`: каскад включён, `move 0`, Vd=Vq=0. Режим VOLTAGE=3 и нулевые Vdq подтверждены контрольным профилем. После записи выполнен arm0/1 с захватом текущей позы; прежняя цель не возвращалась.

В токовом режиме Id до LPF от−0.331 до+0.352А, выраженный пик≈1250Гц; он сохраняется после LPF. В другом, контрольном окне тот же пик у измеренного Id и Vd; Vd от−0.142 до+0.138В. Iq/Vq имеют пик около1000Гц. Это частоты дискретной записи с шагом спектра62.5Гц, не точная оценка собственной частоты мотора.

В VOLTAGE0 аналогичного выраженного колебания Id не видно; STD почти совпадает с выключенным каскадом. Само включение каскада при нулевом напряжении не воспроизводит эффект токового управления.

Шум motor raw близок во всех трёх режимах. В measurement-окне удержания корреляция Id raw с electric angle≈−0.024, с raw encoder≈−0.059. Это только одновременная линейная корреляция без лагов на коротком окне; она не исключает нелинейную/косвенную связь. У электрического угла на этом окне доминируют существенно более медленные изменения, не пик1250Гц.

Во всех выгруженных окнах: late entries0, pending updates0, NDTR-change0, ADC OVR0, DMA TE0, CORDIC INT32_MIN0, saturation/clipping0. Постоянный NDTR не доказывает полную DMA-coherence. Максимальная измеренная длительность ISR body —55.2мкс при периоде62.5мкс; это вариант с overhead диагностики, не WCET штатного варианта.

## Вывод

Получены прямые признаки колебаний в замкнутом токовом контуре, особенно по оси d, уже при практически нулевом задании момента. Гипотеза «рывки целиком создаёт шум энкодера» этим опытом не подтверждается и стала менее убедительной. Энкодер полностью не исключён: часть ошибок угла/коммутации и взаимодействий обратной связи остаётся общей неопределённостью.

Результат пока не разделяет неустойчивость PI с LPF/вычислительной задержкой, особенности реального R/L и помехи измерения, возникающие от управляемой токовым PI модуляции PWM. Измеренные токи не верифицированы независимым пробником. Алиасинг аналоговых помех выше8кГц не исключён. Короткая запись не объясняет механические ступеньки напрямую.

Следующий изолированный опыт нужно согласовать отдельно: изменить только параметры токового PI на поддержанном неподвижном приводе и сравнить тот же нулевой Iq. Выключение Ki не гарантирует исчезновения1250Гц: на этой частоте пропорциональная часть исходного PI существенно больше интегральной. До изменения коэффициентов полезно оценить R/L и фазовый запас с фактической задержкой; параметры наблюдателя пока не менять.

На завершении J3 arm1, удерживает захваченную текущую позу; fault_act0. CAN 1M/4M, tx/rx error counters0, bus-errors0, bus-off0. J1/J2/J4–J6 не прошивались и команд не получали.
